# NIIMBOT N1 — драйвер этикеток для Linux

[![Go](https://img.shields.io/badge/Go-1.24+-00ADD8?logo=go)](https://go.dev)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

**English version:** [README.en.md](README.en.md)

Драйвер термотранспортного принтера этикеток **NIIMBOT N1** по Bluetooth LE.
Написан на Go, работает из командной строки: печатает текст и картинки,
показывает состояние принтера, умеет отрисовать макет без печати.

Никакого приложения вендора, никакого телефона и никаких аккаунтов — только
Linux, Bluetooth и одна команда.

```console
$ niimbot text "Насос" "12А-5"
```

## Возможности

| Команда | Что делает |
|---|---|
| `niimbot info` | состояние принтера: id модели, серийный номер, прошивка, плотность, заряд |
| `niimbot text "строка" "..."` | напечатать текст (каждый аргумент — отдельная строка) |
| `niimbot image file.png` | напечатать картинку |
| `niimbot preview "строка"` | отрисовать макет **без печати** — посмотреть, что уйдёт на этикетку |
| `niimbot testpage` | встроенная тестовая страница принтера (проверка связи) |
| `niimbot scan` | найти принтер в эфире |

## Требования

- **Linux** с BlueZ (проверено на Debian/Ubuntu; используется D-Bus API BlueZ);
- **Go 1.24+** для сборки;
- шрифт с кириллицей (DejaVu, Noto или Liberation — ищутся автоматически);
- принтер **NIIMBOT N1** (для других моделей нужны свои параметры головки — см. «Протокол»).


## Использование

```bash
# посмотреть состояние принтера
./niimbot info

# макет без печати (сохраняется в /tmp/niimbot_label_preview.png)
./niimbot preview "Насос" "12А-5"

# печать текста
./niimbot text "Насос" "12А-5"

# картинка
./niimbot image logo.png

# печать вдвое плотнее, две копии
./niimbot text "ГРК" "инв. 4210" --density 3 --copies 2
```

### Флаги

| Флаг | Значение | По умолчанию |
|---|---|---|
| `--address MAC` | адрес принтера; без него поиск по имени `N1-` | авто |
| `--length мм` | длина этикетки вдоль подачи | `30` |
| `--font точек` | кегль; `0` — подобрать под размер этикетки | `0` |
| `--density 1..3` | плотность печати | `2` |
| `--label` | тип этикетки: `withgaps`, `continuous`, `black`, `perforated`, `transparent`, `pvctag`, `blackmarkgap`, `heatshrink` | `withgaps` |
| `--copies N` | число копий | `1` |
| `--flip` | перевернуть содержимое на 180° | выкл. |
| `-v=false` | без подробного вывода протокола | вкл. |

## Этикетки и ориентация

Принтер N1 печатает головкой на **96 точек** — это **12 мм** при 203 dpi.
У автора этикетки **EW14×30**: 14 мм шириной, 30 мм вдоль подачи
(печатаемая часть — 12 мм по центру).

**Текст идёт вдоль этикетки.** Содержимое рисуется в «ориентации чтения»
(ширина = длина этикетки, высота = ширина головки) и превращается в строки
принтера так:

- **транспонируется** — ось X изображения становится направлением подачи;
- **ось головки идёт в обратном порядке** — точка головки `c` берётся
  из строки изображения как `across-1-c` (в NiimBlueLib это
  `idx = (height-1-col)*width + row`).

Обе тонкости проверены печатью на живом принтере, и обе были ошибками автора:

1. если рисовать «как на экране», текст ложится **поперёк** этикетки;
2. без разворота оси головки этикетка выходит **зеркальной**.

Если этикетка вышла «вверх ногами» — добавьте `--flip` (поворот на 180°).

## Протокол

Пакет:

```
55 55 | команда | длина | данные | XOR-контроль | AA AA
```

Многобайтовые числа — **big-endian**. Контрольная сумма — XOR команды,
длины и всех байт данных.

Цикл печати:

```
плотность (0x21) → тип этикетки (0x23) → старт печати (0x01) →
старт страницы (0x03) → размер страницы (0x13) → строки битмапа (0x85) →
конец страницы (0xE3) → опрос статуса (0xA3) → конец печати (0xF3)
```

Строка битмапа: `позиция(2) | счётчики чёрных точек(3) | повторы(1) | данные(12)`,
где бит 7 первого байта — крайняя точка головки. Полностью белые строки
отправляются отдельной командой `0x84` — это короче и быстрее.

Статус печати (ответ `0xB3`): `страница(2) | прогресс печати % | прогресс подачи %`.
Печать завершена, когда страница ≥ нужной и оба прогресса равны 100.

### Две ловушки, на которые стоит обратить внимание

**1. У принтера два BLE-сервиса, и рабочий только один.**

| Сервис | Что это |
|---|---|
| `e7810a71-73ae-499d-8c15-faa9aef0c3f2` | **родной сервис NIIMBOT** — его слушает прошивка, характеристика `bef8d6c9-9c21-4c9e-b632-bd58c1009f9f` |
| `49535343-fe7d-4ae5-8fa9-9fafd205e455` | прозрачный UART — подходит по свойствам (`notify` + `write`), но **на команды не отвечает вообще** |

Подключение к UART выглядит успешным, но принтер молчит: команды уходят
«в пустоту». Именно на это уходит больше всего времени при отладке.

**2. BlueZ нужно сначала «увидеть» устройство.**

Без предварительного сканирования подключение падает с ошибкой D-Bus:

```
Method "Get" with signature "ss" on interface "org.freedesktop.DBus.Properties" doesn't exist
```

Плюс важная деталь для Go: `Adapter.Scan` у Linux-бэкенда библиотеки
`tinygo.org/x/bluetooth` **блокируется до `StopScan`** — его нужно запускать
в отдельной горутине, иначе программа зависнет.

### Другие модели

Параметры привязаны к N1: id модели `3586`, головка `96` точек, плотность `1..3`.
Для другой модели нужно поменять эти значения в `protocol.go`
(таблица соответствий «модель → параметры» есть в
[NiimBlueLib](https://github.com/MultiMote/niimbluelib/blob/master/src/printer_models.ts)).

## Тесты

```bash
go test ./...
```

Тесты проверяют сборку пакетов **сверкой с байтами, снятыми с живого принтера**
(рукопожатие `5555c10101c1aaaa`, запрос модели `555540010849aaaa`), разбор
ответов, склейку неполных пакетов, счётчики точек, ориентацию строк
и белый фон холста.

## Что проверено, а что нет

**Проверено на живом принтере N1 (GA24110447):**

- поиск, подключение и рукопожатие;
- id модели `3586`, серийный номер, прошивка `3.13`, заряд;
- **печать этикеток** — полный цикл: `страница 1, печать 100%, подача 100%`;
- **ориентация** — оттиск читается правильно (текст вдоль этикетки,
  не зеркальный). Подтверждено на бумаге после двух исправлений,
  описанных выше;
- на печати же выяснились обе ошибки ориентации — их без физического
  оттиска не поймать.

**Пока не проверено:**

- печать на других типах этикеток (`--label`), кроме `withgaps`;
- другие модели NIIMBOT (нужны свои параметры головки);
- печать картинок (`image`) — путь тот же, что и у текста, но на бумаге
  не проверялся.
